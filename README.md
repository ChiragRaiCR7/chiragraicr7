## Featured Projects

### 1) Agentic AI Automation Suite
**Repo:** github.com/ChiragRaiCR7/agentic-suite  
**TL;DR:** Multi-agent orchestration for email & IT ticket automation using Microsoft Autogen + custom LLM flows.  
**Stack:** Python, Autogen, LLaMA (LoRA), FAISS, Docker, GCP (Cloud Run)  
**How to run:** `docker-compose up` or follow the `quickstart.md` in repo. Includes demo scripts and sample prompts.  
**Result:** Automated resolution for common tickets with ~85% closed-loop accuracy in staging; 60–80% reduction in manual triage for documented ticket classes.

### 2) LLaMA Fine-tuning (Domain Models)
**Repo:** github.com/ChiragRaiCR7/llama-finetune  
**TL;DR:** LoRA-based fine-tuning pipeline, model cards, evaluation notebooks and a reproducible inference endpoint.  
**Stack:** PyTorch, Transformers, LoRA, Hugging Face, FAISS, Docker, GitHub Actions
